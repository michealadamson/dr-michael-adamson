# Dr. Michael Adamson — Official Website

GitHub Pages-ready static website.

Repository: `michealadamson/dr-michael-adamson`

## Publish
Go to **Settings → Pages → Deploy from a branch**, select `main` and `/ (root)`, then Save.

Intended domain: `drmichaeladamson.com`

The website includes an Awards section documenting the 14 December 2025 Award of Special Appreciation presented to Pastor Michael Adamson by Mountain of Fire and Miracles Ministries, Lagos Region 152, Ojodu Abiodun Regional Headquarters, for invaluable service in God's vineyard.
